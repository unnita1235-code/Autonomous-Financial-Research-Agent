# Gold Standard: Microsoft Profile
**Ticker:** MSFT
**Sector:** Technology
**Industry:** Software—Infrastructure

Microsoft is a global leader in software, services, devices, and solutions. Key segments include Productivity and Business Processes (Office, LinkedIn), Intelligent Cloud (Azure), and More Personal Computing (Windows, Gaming). 

**Key Metrics (Approx):**
- Market Cap: $3.1T
- ROE: 38%
- Operating Margin: 44%

**Investment Thesis:** Strong cloud growth via Azure and AI integration (Copilot) offset by cyclical hardware headwinds.
